# Django-приложение: Users & Roles

Веб-приложение на Django с кастомной аутентификацией, ролевой моделью (RBAC) и панелью управления пользователями.

## Стек технологий
* **Python**: 3.12+
* **Django**: 5.x / 6.x
* **База данных**: SQLite (по умолчанию для разработки)
* **Аутентификация**: встроенная подсистема `django.contrib.auth` (без кастомной модели пользователя)
